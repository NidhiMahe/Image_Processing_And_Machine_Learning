# 🧠 Computer Vision Projects Portfolio

A collection of Jupyter Notebook projects demonstrating core to advanced computer vision techniques using libraries like OpenCV, scikit-image, DeepFace, and FaceNet.

---

## 🧾 Overview

Image processing plays a vital role in enhancing visual data, enabling feature extraction, and supporting a wide range of transformations. Basic operations—such as color conversion, shape detection, and drawing—can be efficiently performed using libraries like **scikit-image**.

For more advanced tasks like **image blending**, **masking**, and **face detection**, **OpenCV** offers a robust suite of tools and functions. As complexity increases, particularly in areas like **face recognition**, **object detection**, and **semantic segmentation**, deep learning becomes essential.

Libraries such as **FaceNet**, **DeepFace**, and custom-built **facial recognition models** provide high-accuracy solutions for real-world applications. For broader AI development, frameworks like **TensorFlow** and **PyTorch** are critical for designing, training, and deploying deep learning models.

Mastering these tools and techniques opens the door to building powerful and scalable computer vision systems.

##  Basic Level

### OpenCV.ipynb  
Introduced OpenCV fundamentals including image reading, display, and manipulation.  
Serves as the foundation for more advanced computer vision tasks.

### Basic_Drawing_On_Image.ipynb  
Implemented basic OpenCV drawing functions to annotate images with lines, circles, and text.  
Practiced coordinate-based graphics overlays on static images.

### Dilation_Errosion.ipynb  
Demonstrated morphological operations like dilation and erosion using OpenCV.  
Used for refining binary images and preparing for contour detection.

---

##  Intermediate Level

### skimage_OpenCv_Image_contrast.ipynb  
Compared contrast enhancement techniques using `skimage` and OpenCV.  
Applied histogram equalization and CLAHE for better visual quality.

### scikit_image.ipynb  
Explored the `scikit-image` library for essential image processing tasks.  
Implemented filters, edge detection, and transformation functions.

### haarface_cascade.ipynb  
Used Haar cascade classifiers to detect faces in real-time from images or webcam.  
Implemented object detection using traditional machine learning techniques.

---

##  Advanced Level

###  SIFT_ImageComparion_Diff_Scale-Angle.ipynb  
Used SIFT (Scale-Invariant Feature Transform) to compare and match images at various angles and scales.  
Tested feature descriptor robustness with keypoint detection and matching.

### OpenCV2_Advance_Image_Processing_Blending_....ipynb  
Worked on advanced image blending and masking using OpenCV.  
Demonstrated techniques like pyramid blending and seamless cloning.

### Facerecognization.ipynb  
Built a facial recognition system using OpenCV and face encodings.  
Enabled face detection and recognition in live video or image data.

### DeepFace.ipynb  
Applied the DeepFace library for facial attribute analysis and recognition.  
Used pre-trained models for age, emotion, and identity detection.

###  facenet.ipynb  
Implemented FaceNet for high-accuracy face recognition using embeddings.  
Performed face verification based on deep feature similarity.
